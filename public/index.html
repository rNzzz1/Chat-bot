Бот Сейчас
Привет! Я простой чат-бот с локальной логикой. Я могу ответить на приветствия, вопросы о погоде, времени и самочувствии. Просто напишите мне что-нибудь!
Попробуйте: "привет", "как дела", "какая погода", "который час", "пока"

Информация о боте

  • Технологии: Node.js, Express.js, JavaScript
  • Логика: Локальная, без внешних API
  • Возможности: Ответы на приветствия, вопросы о погоде, времени и т.д.
  • API: Доступно по адресу /api/chat
